## ✨ Features

### Sections
- **Header** — Sticky nav with logo, links, CTA button, mobile hamburger menu
- **Hero** — Full-viewport background image, animated headline, stats bar, scroll indicator
- **Popular Destinations** — 4 destination cards (Bali, Dubai, Maldives, Switzerland) with hover effects
- **Travel Packages** — 3 all-inclusive package cards with pricing
- **Why Choose Us** — 3 key benefits with icon cards on a dark background
- **Testimonials** — 3 customer review cards
- **Final CTA** — Full-bleed call-to-action section
- **Footer** — Brand info, quick links, destinations, contact details, social icons

### Design
- Clean, modern, travel-focused aesthetic
- CSS custom properties for easy theming
- Smooth scroll-reveal animation on all cards/sections
- Subtle card tilt effect on destination cards
- Fully responsive: desktop → tablet → mobile

### Functionality
- Sticky header with blur/shadow on scroll
- Mobile slide-down navigation with hamburger animation
- Active nav link tracking via `IntersectionObserver`
- Smooth scrolling for all anchor links
- Scroll-to-top on logo click
- No external JS dependencies

## 🚀 Deployment

### Vercel (Recommended)
1. Push this repo to GitHub (public)
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repository
4. Leave all defaults → click **Deploy**
5. Your site is live! 🎉

### Netlify (Alternative)
1. Go to [netlify.com](https://netlify.com) → **Add new site → Import an existing project**
2. Connect GitHub and select the repo
3. Click **Deploy site**
